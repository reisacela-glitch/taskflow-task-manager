# TaskFlow – Task Management App

A clean, responsive task management application designed to help users organize their daily tasks, track progress, and stay productive.

## 🌐 Live Demo

[View TaskFlow](https://taskflow-management-app.netlify.app/)

## ✨ Features

- **Add Tasks** – Create new tasks with a title, priority, and due date.
- **Edit Tasks** – Update existing task information.
- **Delete Tasks** – Remove tasks you no longer need.
- **Task Completion** – Mark tasks as completed or pending.
- **Task Filtering** – Filter tasks by All, Pending, and Completed.
- **Search Tasks** – Quickly find tasks using the search functionality.
- **Priority Levels** – Organize tasks by Low, Medium, and High priority.
- **Due Dates** – Set deadlines for your tasks.
- **Dashboard Statistics** – Track total, pending, and completed tasks.
- **Local Storage** – Automatically save tasks in the browser.
- **Responsive Design** – Adapted for desktop, tablet, and mobile devices.

## 🛠️ Technologies Used

- CSS3
- JavaScript (Vanilla JavaScript)
- Local Storage API

## 🚀 Getting Started

To run this project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/reisacela-glitch/taskflow-task-manager.git
   ```

2. Open the project folder:

   ```bash
   cd taskflow-task-manager
   ```

3. Open `index.html` in your browser or use the VS Code Live Server extension.
